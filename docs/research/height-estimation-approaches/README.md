# Подходы к оценке роста человека

Данная папка посвящена исследованию методов оценки роста человека по видеоданным (изображениям).

Общие правила ведения исследований описаны в родительской директории. Ссылки на источники собираются в файле [sources.md](./sources.md). Подробные заметки по методам находятся в папке [approaches/](./approaches/).
