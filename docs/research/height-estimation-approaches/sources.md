# Реестр источников: Оценка роста человека

В данном файле собираются все ссылки на статьи, кодовые базы и датасеты, относящиеся к методам оценки роста.

## Научные статьи

1. **What Face and Body Shapes Can Tell About Height (Günel et al., 2018)**
   * Ссылка: [https://arxiv.org/pdf/1805.10355](https://arxiv.org/pdf/1805.10355)
   * Краткое описание: Оценка роста по пропорциям костей, позе и чертам лица без калибровки камеры.

2. **Human height estimation using AI-assisted computer vision for intelligent video surveillance system (Yogameena et al., 2024)**
   * Ссылка: [https://www.sciencedirect.com/science/article/abs/pii/S0263224124010182](https://www.sciencedirect.com/science/article/abs/pii/S0263224124010182)
   * Краткое описание: Метод для систем видеонаблюдения с использованием YOLOv7-Occlusion Aware и анализа параметров камеры.

3. **Adaptive Silhouette Refinement: A Novel Computer Vision Approach for Precise Height Estimation in Diverse Cultural Context (Davis, 2025)**
   * Ссылка: [https://zenodo.org/records/16843707](https://zenodo.org/records/16843707)
   * Краткое описание: Метод анализа силуэта с адаптивным уточнением границ для борьбы с окклюзиями.
