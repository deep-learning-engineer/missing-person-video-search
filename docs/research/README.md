# Исследовательские заметки (Research)

Данная директория предназначена для изучения и документирования теоретических материалов, подходов и архитектур, которые могут быть применены в проекте `missing-person-video-search`.

## Правила организации

Каждая отдельная тема или направление исследования оформляется в виде отдельной папки (например, `height-estimation-approaches/`).

Внутри каждой такой папки соблюдается следующая структура:

1. **`README.md`** — специфичное описание исследуемой темы и таблица со статусами изучаемых подходов.
2. **`sources.md`** — реестр найденных источников (статьи, репозитории, датасеты) по данной теме.
3. **`approaches/`** (опционально) — папка с подробными заметками по каждому отдельному методу или статье. Создается, если требуется глубокое погружение в конкретный подход.

Дополнительные материалы (схемы, выгрузки данных, важные текстовые файлы), если они относятся к теме, также могут храниться внутри папки темы.


### Ведение таблицы подходов

В `README.md` каждой темы ведётся таблица подходов. Она выполняет роль краткого реестра и позволяет оценить состояние изучения темы без обращения к подробным заметкам.

Рекомендуемые колонки таблицы:

| Колонка | Назначение |
|---|---|
| **Название** | Краткое наименование подхода, статьи или метода. |
| **Краткое описание** | Одно–два предложения о сути подхода и его релевантности проекту. |
| **Статус** | Текущее состояние изучения подхода — строго одно из значений статусной модели, приведённой ниже. |

### Статусная модель

| Статус | Определение |
|---|---|
| **В планах** | Подход представляет интерес и будет изучен в порядке общей очереди. |
| **Изучается** | Источник или подход находится в стадии прочтения и анализа. Ключевые выводы ещё не зафиксированы. |
| **Изучено** | Необходимая информация получена и зафиксирована. Подход может быть использован для проектных решений. |
| **Тестируется** | Подход проверяется на данных или в прототипе. Фиксируются метрики, ограничения и условия применимости. |

При добавлении нового источника сначала вносится запись в `sources.md`, затем — строка в таблицу подходов в `README.md`, если источник претендует на отдельный подход или метод.
